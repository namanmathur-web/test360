# Test360 MVP flow (7 pages)

Loop: Landing -> Home (personal dashboard) -> Chapter summary -> Build a test -> Take test -> Result -> Next steps -> back to Home.
Everything on every page is personalised to the student's last attempts: weak topics, last score, level, XP, streak.

1. **Landing / onboarding** - explain the product, pick exam and subject, show prices (pack Rs 99, series Rs 2,999). Returning students skip to Home.
2. **Home (personal dashboard)** - Today card (what to do next), title and XP, week streak, before -> after score, missions, subject tabs, chapter rows with last score, topics to fix, Free / Pack tags.
3. **Chapter summary** - 6-topic strip, sections where marks were lost move up ("You lost N marks here last time"), Got it +5 XP, Ved pattern card, teacher clip, notes card.
4. **Build a test** - smart defaults: weak topics ticked, recommended level, XP multiplier, "Beat your last score" card. Levels 1-5, all open.
5. **Take the test** - timer, question palette, mark for review, +4 / -1 marking (numerical has no negative).
6. **Result** - score, topic breakdown, mistake types (Rushed / Concept slip / Not attempted), Ved persona, Answers tab with "Try a similar question", "Reattempt at Level +1", "Teacher clip".
7. **Next steps** - three equal cards: same topic higher level, next topic, fix what went wrong. Then Rs 99 pack and Rs 2,999 series (hidden if already bought).

Open questions: lower half of the whiteboard was cut off ("same summary topic wise"); Level 1-5 tags on the question bank; whether returning students ever see page 1 again.
