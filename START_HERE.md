# How to put this on GitHub (no coding needed)
1. Go to github.com, sign in, click + (top right) -> New repository.
2. Name: test360. Choose **Private**. Click Create repository.
3. On the next page click "uploading an existing file".
4. Unzip test360-repo.zip on your computer. Open the folder, select EVERYTHING inside (including CLAUDE.md), drag into the GitHub page.
   If GitHub complains about too many files, upload in 2-3 batches (e.g. first CLAUDE.md, MVP_FLOW.md, demo; then reference).
5. Click Commit changes.
6. Go to claude.ai/code, connect GitHub, pick test360, and start a session with:
   "Read CLAUDE.md and MVP_FLOW.md, open the demo, and tell me your plan for making this a real app."
